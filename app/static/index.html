x xam calls

Тестовый клиент аудио- и видеозвонков и конференций. Авторизация — через соседний xam_backend, медиа идёт напрямую по WebRTC.

или
Подключиться по токену xam

Токен можно передать из мессенджера в hash-части ссылки: #token=<jwt> — hash не отправляется на сервер.

Бэкенд: localhost:8000. Откройте клиент на localhost или по HTTPS — иначе браузер заблокирует камеру.
